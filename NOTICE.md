The original Antiyoy game was created by **Yiotro**.

Original project: https://github.com/yiotro/Antiyoy

The author's README permits downloading, modifying and running the project, and explicitly prohibits commercial use. This adaptation is intended for non-commercial use. No commercial redistribution rights are claimed.

«Захватчики» is an unofficial adaptation. It is not an official Yiotro release and does not imply endorsement. The network server, Telegram integration and editor implementation were implemented for this project.

The 14 unmodified PNG files in `public/assets/antiyoy/` are original artwork by Yiotro, copied from `yiotro/Antiyoy` at commit `f22acaa0d08cc908b9d236bfabc28f93d059ad3e`. They include the coin, undo/end-turn icons, castle, house, towers, trees, grave and four units. These assets remain subject to the upstream non-commercial restriction. The existing favicon is unchanged.

Additional rules research: https://github.com/yiotro/antiyoy_hd at commit `120bd3c60eef1eccdda583cd5d9d70b1c493e4f5`. See `docs/UPDATE-2026-09-25.md` for the distinction between source rulesets and the supplied screenshots.

Do not remove attribution when adding original assets. Preserve upstream usage restrictions, and seek the author's permission before monetization or commercial distribution.
